    How it works, and calling it from Postman or curl

    This page sends your goal to the n8n workflow AI Prompt Generator — Multi-Model Evaluation as a POST to its production webhook. A plain browser visit to that URL fails, because browsers send GET.

    1. Three agents each draft a prompt: creative (Gemini), marketing (DeepSeek through OpenRouter), technical (GPT-OSS on Groq).
    2. An evaluator (Gemini) compares them against your goal and keeps the winner word for word: version 1, Refined.
    3. A refiner sharpens it: role, audience, constraints and output format spelled out. Version 2, More refined.
    4. A second refiner makes that production-ready: context, steps, quality criteria, edge cases, an example. Version 3, Most refined.
    5. The workflow answers with {"goal", "best_prompt", "choices": [{"level", "label", "prompt"} ×3]} and saves the goal and version 1 to Supabase.

    Each run calls six models on your own API keys. The workflow must be published for the webhook to answer.
